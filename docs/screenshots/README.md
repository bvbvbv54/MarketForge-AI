# Screenshot Guidelines

Capture screenshots from a sanitized demo environment only.

Recommended images:

1. `01-product-intelligence-dashboard.png` - main Product Intelligence workspace.
2. `02-opportunity-report.png` - product opportunity score and score explanation.
3. `03-keyword-explorer.png` - keyword demand and opportunity table with fake sample data.
4. `04-competitor-analysis.png` - competitor analysis with anonymized competitors.
5. `05-ai-image-plan.png` - image strategy recommendations.
6. `06-product-package-export.png` - export workflow for PDF and marketplace CSVs.

Do not include:

- Source code.
- Terminal windows.
- API keys.
- Provider dashboards.
- Internal logs.
- Real customer or supplier data.
- Private product URLs.
